## 🧠 PRODUCT VISION

Whispr is an anonymous video recommendation platform. A user finds a video on YouTube, Instagram, TikTok, Facebook, or any public URL — and sends it to someone they care about, anonymously. The recipient receives it via:
- **Whisper Link** — an anonymous SMS or email with a beautiful landing page
- **Ghost Boost** — a micro-targeted Meta/TikTok ad that places the video in their social feed

The sender can track when the recipient opened or watched the content. They can optionally reveal themselves. The recipient can respond anonymously. Emotion drives the use case — couples, parents, children, friends, coworkers.

## 🗄️ DATABASE SCHEMA (Supabase PostgreSQL)

```sql
-- USERS
create table users (
  id uuid primary key default gen_random_uuid(),
  email text unique not null,
  full_name text,
  avatar_url text,
  plan text default 'free', -- 'free' | 'spark' | 'ember'
  boost_credits integer default 0,
  whisper_links_used integer default 0,
  whisper_links_reset_at timestamp,
  stripe_customer_id text,
  stripe_subscription_id text,
  created_at timestamp default now()
);

-- WHISPS (core send unit)
create table whisps (
  id uuid primary key default gen_random_uuid(),
  sender_id uuid references users(id),
  video_url text not null,
  video_title text,
  video_thumbnail text,
  video_platform text, -- 'youtube' | 'tiktok' | 'instagram' | 'facebook' | 'other'
  delivery_method text not null, -- 'whisper_link' | 'ghost_boost'
  recipient_email text,
  recipient_phone text,
  recipient_meta_audience_id text,
  anonymous_note text, -- max 200 chars
  sender_alias text, -- 'Someone who cares' | 'A friend' | custom
  status text default 'pending', -- 'pending' | 'delivered' | 'opened' | 'watched' | 'replied'
  scheduled_at timestamp,
  delivered_at timestamp,
  opened_at timestamp,
  watched_at timestamp,
  reveal_requested boolean default false,
  reveal_accepted boolean default false,
  boost_spend_usd numeric(6,2),
  created_at timestamp default now()
);

-- ANONYMOUS REPLIES
create table whisp_replies (
  id uuid primary key default gen_random_uuid(),
  whisp_id uuid references whisps(id),
  reply_text text not null, -- max 300 chars
  from_recipient boolean default true,
  created_at timestamp default now()
);

-- CREDIT TRANSACTIONS
create table credit_transactions (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references users(id),
  type text, -- 'purchase' | 'spend' | 'refund' | 'plan_grant'
  amount integer,
  whisp_id uuid references whisps(id),
  stripe_payment_intent_id text,
  created_at timestamp default now()
);

-- TRACKING EVENTS (pixel + link click)
create table tracking_events (
  id uuid primary key default gen_random_uuid(),
  whisp_id uuid references whisps(id),
  event_type text, -- 'opened' | 'clicked' | 'watched_10s' | 'watched_50pct' | 'watched_complete'
  user_agent text,
  ip_hash text,
  created_at timestamp default now()
);

-- MOOD TAGS (value-added feature)
create table mood_tags (
  id uuid primary key default gen_random_uuid(),
  label text not null, -- 'Heal Together' | 'I See You' | 'Think About This' | 'I Love You' | 'For Your Growth'
  emoji text,
  color_hex text
);

-- ROW LEVEL SECURITY
alter table whisps enable row level security;
alter table users enable row level security;
alter table whisp_replies enable row level security;

create policy "Users see own whisps" on whisps
  for select using (auth.uid() = sender_id);

create policy "Users update own profile" on users
  for update using (auth.uid() = id);
```

### 5. REVEAL FLOW

**Sender initiates reveal:**
- Clicks "Reveal Yourself" on their whisp detail page
- App sends recipient an anonymous notification: *"The person who sent you this video wants to reveal themselves. Do you want to know who it was?"*
- If recipient accepts → both see each other's identity
- If recipient declines → sender is notified, identity stays hidden
- *(Ember tier only)*

---

### 6. ANONYMOUS REPLY INBOX

- Threaded anonymous conversation per whisp
- Recipient replies from the landing page
- Sender receives push/email notification: *"Someone replied to your whisp"*
- Both sides stay anonymous unless reveal is triggered
- *(Spark + Ember)*

## 🌟 PREMIUM FEATURES (Ember Tier Exclusives)

### 1. Mood Tags
Pre-built emotional context tags the sender chooses before sending. Changes the visual theme of the recipient's landing page.
- 💛 "I See You" → warm gold theme
- 🕊️ "Heal Together" → soft blue theme
- ❤️ "I Love You" → rose theme
- 🌱 "Think About This" → green theme
- 💪 "For Your Growth" → deep purple theme
- 🙏 "Just Because" → neutral cream theme

### 2. Reveal Flow
Full two-way identity reveal system with consent on both sides. Notification chain, acceptance UI, reveal moment screen.

### 3. Family Circle
Group of up to 5 people (family members, close friends) stored in account. Send whisps to Circle members with one click. Shared history visible. Circle members can see non-anonymous replies within the circle.

### 4. Weekly Impact Digest
Automated beautiful email every Monday summarizing: videos sent, open rates, replies received, most impactful whisp of the week (most engagement). Designed to feel like a "relationship health report."

### 5. Deep Analytics per Whisp
- Watch percentage (via YouTube embed events)
- Time from delivery to open
- Reply sentiment (AI-powered: positive/neutral/reflective)
- Engagement score (0–100)
